# 1. Record architecture decisions

- Status: accepted
- Date: 2026-11-02

## Context

Decisions about the licence boundary, the privacy guarantees and the packaging are easy to lose
in issue threads, and new contributors cannot tell which choices are deliberate.

## Decision

We record significant decisions as short, numbered Markdown files in `docs/adr/`, following
the [ADR format](https://adr.github.io/): context, decision, consequences. A decision that is
replaced is not deleted; its status changes to *superseded by NNNN*.

## Consequences

Contributors can read the reasoning before proposing a change, and maintainers can point to it
in reviews. The cost is a few minutes of writing per decision.
