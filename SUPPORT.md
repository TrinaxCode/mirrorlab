# Getting help

| I want to… | Go to |
| --- | --- |
| Install it or fix something that does not work | Run `mirrorlab doctor`, then read the [FAQ](docs/FAQ.md) and the [desktop guide](docs/DESKTOP.md) |
| Ask a question or show what I built | [GitHub Discussions](https://github.com/TrinaxCode/mirrorlab/discussions) |
| Report a bug | [Open an issue](https://github.com/TrinaxCode/mirrorlab/issues/new/choose) and paste the output of `mirrorlab doctor` |
| Suggest a feature | [Open a feature request](https://github.com/TrinaxCode/mirrorlab/issues/new/choose), or start a Discussion first if it is still an idea |
| Report a security problem | [Private advisory](https://github.com/TrinaxCode/mirrorlab/security/advisories/new), never a public issue. See [SECURITY.md](SECURITY.md) |
| Contribute code, docs or a translation | [CONTRIBUTING.md](CONTRIBUTING.md) and [docs/TRANSLATING.md](docs/TRANSLATING.md) |

MirrorLab is maintained in spare time by volunteers. There is no support contract and no
guaranteed response time, but every issue is read.
